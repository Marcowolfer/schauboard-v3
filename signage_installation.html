🖥️ 3dWolf Signage

Installationsanleitung — Server-Setup & Konfiguration

📋 1. Voraussetzungen

Für die Installation von 3dWolf Signage benötigen Sie:

Hardware

  • Synology NAS (oder alternativer Webserver mit PHP-Unterstützung)
  • Mindestens 100 MB freier Speicherplatz
  • Netzwerkverbindung für den Kiosk-Display-Client

Software

  • PHP 8.x oder höher
  • Web Station (bei Synology) oder Apache/Nginx
  • Write-Berechtigungen für den Webserver-Benutzer
💡 Auf Synology NAS aktivieren Sie Web Station im Package Center und stellen sicher, dass PHP 8.x installiert ist.

📁 2. Dateistruktur

Das System verwendet folgende Verzeichnisstruktur:

📁 signage/
  • 📄 index.php — Hauptdisplay (Kiosk-Ansicht)
  • 📄 weather.php — Wetter-API-Proxy
  • 📁 admin/
    • 📄 index.php — Admin-Editor
  • 📁 data/
    • 📄 slides.json — Folien-Konfiguration
    • 📄 settings.json — Globale Einstellungen
    • 📄 last_update.txt — Zeitstempel für Live-Update
  • 📁 uploads/
    • Hochgeladene Bilder, Videos und PDFs

🔧 3. Installation

Folgen Sie diesen Schritten zur Installation:

  1. Ordner erstellen
    Erstellen Sie auf Ihrem Webserver das Verzeichnis signage/ im Web-Root (z.B. /web/signage/ auf Synology).
  2. Unterordner anlegen
    Erstellen Sie innerhalb von signage/ folgende Ordner:
    mkdir admin data uploads
  3. Dateien hochladen
    Kopieren Sie alle PHP-Dateien in die entsprechenden Verzeichnisse:
    • index.php → signage/
    • weather.php → signage/
    • admin/index.php → signage/admin/
  4. Rechte setzen
    Setzen Sie Schreibrechte für den Webserver-Benutzer:
    # Synology (im Terminal als admin) sudo chmod -R 775 /volume1/web/signage/data sudo chmod -R 775 /volume1/web/signage/uploads sudo chown -R http:http /volume1/web/signage/data sudo chown -R http:http /volume1/web/signage/uploads
  5. Browser öffnen
    Öffnen Sie im Browser:
    http://[Ihre-IP]/signage/admin/

    Die Login-Maske sollte erscheinen.
✓ Bei erfolgreicher Installation sehen Sie die Login-Seite mit Passwortabfrage.

🔐 4. Passwort ändern

Das Admin-Passwort ist in der Datei admin/index.php hinterlegt:

// Zeile ~7 in admin/index.php define('ADMIN_PASSWORD', 'H0l2bau$');

So ändern Sie das Passwort:

  1. Öffnen Sie admin/index.php in einem Texteditor
  2. Suchen Sie nach Zeile 7 (Definition von ADMIN_PASSWORD)
  3. Ersetzen Sie 'H0l2bau$' durch Ihr neues Passwort
  4. Speichern und wieder hochladen
⚠️ Verwenden Sie ein sicheres Passwort mit mindestens 12 Zeichen, inklusive Groß- und Kleinbuchstaben, Zahlen und Sonderzeichen.

🖥️ 5. Kiosk-Display einrichten

Für einen Windows-PC als Info-Display:

Chrome Kiosk-Modus

  1. Erstellen Sie eine Verknüpfung zu Chrome mit folgendem Ziel:
    "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --noerrdialogs --disable-infobars http://192.168.51.21/signage/
  2. Legen Sie diese Verknüpfung im Windows-Autostart-Ordner ab:
    %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup

Windows Autostart-Konfiguration

  1. Drücken Sie Win + R und geben Sie shell:startup ein
  2. Kopieren Sie die Chrome-Verknüpfung in den geöffneten Ordner
  3. Beim nächsten Windows-Start startet Chrome automatisch im Kiosk-Modus
💡 Der Kiosk-Modus startet Chrome im Vollbild ohne Adressleiste, Tabs oder Buttons. Zum Beenden drücken Sie Alt+F4.

🛠️ 6. Troubleshooting

Problem Ursache Lösung
Bilder werden nicht angezeigt Fehlende Schreibrechte Rechte für uploads/ auf 775 setzen und http-Benutzer als Besitzer festlegen
PDF wird nicht geladen Veralteter Browser Chrome/Firefox auf aktuelle Version updaten
Display aktualisiert nicht last_update.txt fehlt Prüfen ob data/last_update.txt existiert und beschreibbar ist
Login funktioniert nicht Falsches Passwort Passwort in admin/index.php überprüfen
Server Error 500 PHP-Version zu alt PHP 8.x oder höher installieren (Web Station Einstellungen)

Log-Dateien prüfen

Bei Problemen können Sie die PHP-Fehlerlogs einsehen:

# Synology /var/log/httpd/apache24-error-log # Oder PHP-Fehler im Browser aktivieren (temporär in index.php) error_reporting(E_ALL); ini_set('display_errors', 1);
