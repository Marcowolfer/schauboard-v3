# Schauboard v3

Neuaufbau von Schauboard v3.

## Status

- Neuer Projektstart auf Basis des v3-Konzepts
- v2.0.1 bleibt der Live-Stand
- Der alte Beta-Stand wird nicht weiterentwickelt

## Struktur

- `core/` gemeinsame Logik, Storage, Auth, Version
- `admin/` Backend und Editor
- `display/` öffentliche Anzeige
- `api/` JSON-Endpunkte
- `data/` Inhalte, Templates, Cache, Auth-Dateien
- `uploads/` Medien
- `docs/` Projektdokumentation
